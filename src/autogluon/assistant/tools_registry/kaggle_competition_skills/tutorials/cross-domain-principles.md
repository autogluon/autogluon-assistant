# Cross-Domain Universal Principles (Layer 3 Wisdom)

Validated across 20+ competitions:

1. **work_smart_not_hard**: External data fusion ROI ~7x self-training
2. **local_optimum_trap**: 3× <0.0001 improvement → pivot direction
3. **simple_diagnostic**: 1-line diagnostic > complex debugging
4. **quality_over_quantity**: 4-6 high-quality models > 23 mediocre ones
5. **signal_dilution**: High-correlation models (>0.97) dilute ensemble
6. **bundle_causes_uninterpretable**: Never change 2+ variables at once
7. **metric_asymmetry**: Asymmetric penalties (RMSLE, Jaccard) require special handling
8. **controlled_variable**: One hypothesis per experiment
9. **consensus_anchor**: >99% consensus disagreement = systematic error
10. **integration_dominance**: How you combine > what you combine
11. **ground_truth_encoding**: Deterministic rules > statistical models when rules exist
12. **distribution_mismatch**: Non-representative validation → predictable LB failure
13. **diagnosis_first**: Understand failure before iterating fixes
14. **foundation_model_vs_gbdt**: Foundation models excel zero-shot; GBDT+lags better for structured lags
15. **multi_horizon_challenge**: Recursive forecasting accumulates errors; LOCF or direct is safer
16. **cv_lb_gap_acknowledgment**: OOF ≠ LB, especially for small data and multi-horizon tasks
